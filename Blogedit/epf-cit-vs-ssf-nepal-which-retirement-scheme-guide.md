<h2 id="tldr">Quick Answer (TL;DR)</h2>

<strong>Government job → EPF (~10%+10% — confirm on epf.org.np) + optional CIT. Private formal → SSF (11%+20%) + optional CIT top-up.</strong> SSF adds <strong>medical/accident/dependent + pension</strong>; EPF is <strong>PF + loans</strong>; CIT is <strong>voluntary growth + gratuity fund manager</strong>. You <strong>can hold SSF + CIT</strong> — registering the same salary in both SSF + EPF simultaneously is commonly described as not permitted, but the exact dual-coverage rule could not be verified against a live SSF/EPF notice as of October 2026 — confirm with the funds before assuming.

<h2 id="compare">EPF vs CIT vs SSF — Side by Side</h2>

- **SSF — 11% + 20% = 31% basic** — Mandatory private formal; PF 20% + gratuity 8.33% + protection ~2.67%; pension/lump-sum + medical/accident
- **EPF — ~10% + 10% basic** — Mandatory civil/public (confirm the current employer/employee split on <a href="https://epf.org.np" target="_blank" rel="noopener noreferrer">epf.org.np</a> — rates move by notice); PF accumulation + annual profit + special/housing loans; lump-sum at retirement
- **CIT — flexible % of salary** — Voluntary/top-up; Employee Savings Growth, Gratuity, Pension-type plans; employer may route gratuity via CIT
- **Tax** — All approved contributions deductible within IRD caps (confirm current caps; the 'SSF skips 1% SST' claim is unverified — see FAQ)

<h2 id="which">Which One Are You In?</h2>

- <strong>Civil servant / public enterprise / school (approved):</strong> EPF via office + add CIT voluntarily for extra growth
- <strong>Private company / bank / NGO / industry:</strong> SSF via employer (check passbook on ssf.gov.np) + add CIT if you want more than 31%
- <strong>Self-employed / foreign-employed:</strong> voluntary SSF schemes + CIT savings plan — confirm current eligibility notice

<h2 id="both">Holding Two + Withdrawal Rules</h2>

- **SSF + CIT** — Allowed — SSF deducted first, CIT as extra %; separate statements, separate claims
- **EPF + CIT** — Classic combo — EPF from payroll, CIT growth/gratuity via same/different employer
- **Withdrawal** — SSF: pension/lump-sum per retirement/exit rule; EPF: PF + profit on retirement/resign/loan; CIT: per plan maturity + loan facility
- **Job change** — Transfer SSF to new employer (one ID); EPF/CIT transfer/continue — never double-register same salary in SSF + EPF
