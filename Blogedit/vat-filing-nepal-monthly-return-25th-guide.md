<h2 id="tldr">Quick Answer (TL;DR)</h2>

If you are VAT-registered, file a <strong>monthly VAT return by the 25th of the following Nepali month</strong> at <strong>taxpayerportal.ird.gov.np</strong> — even if turnover was zero (<strong>Nil return</strong>). <strong>Payable = 13% Output VAT − eligible Input VAT</strong>; Nil if no sales. <strong>Late = per-period fee + interest</strong> on unpaid VAT. Keep <strong>Rule 17 VAT invoices</strong> with VAT shown separately.

<h2 id="who-must-file">Who Must File?</h2>

- <strong>Every VAT-registered person</strong> — goods, services or mixed — monthly by default
- <strong>Approved bi-monthly/trimester filers:</strong> only where the Tax Officer has issued a written approval (certain sectors) — confirm on your approval letter
- <strong>Not VAT-registered (PAN-only):</strong> do not file VAT returns; file annual income tax + e-TDS as applicable

<h2 id="when">When — The 25th Rule</h2>

- **Monthly** — By 25th of the next Nepali month (e.g., Shrawan return by Bhadra 25)
- **Bi-monthly / trimester** — By 25th of the month following the approved period as per approval letter
- **Nil period** — Same deadline — Nil return required
- **Holiday** — If 25th is a public holiday, IRD notice may extend to next working day — verify that month’s notice

<h2 id="how-file">How to File (E-Filing) Step-by-Step</h2>

<h3 id="what-you-need">What You Need Before Filing</h3>

- IRD login at <strong>taxpayerportal.ird.gov.np</strong> (taxpayerportal.ird.gov.np via ird.gov.np)
- Sales register + VAT invoices issued (Rule 17 — VAT shown separately, buyer PAN/VAT)
- Purchase register + VAT invoices received (eligible Input VAT only)
- Debit/credit notes issued or received in the period (returns, discounts)
- Opening credit from previous period (if Input > Output last month)
- Payment method ready via connectIPS/eSewa/IRD revenue if payable

1. <strong>Log in</strong> to taxpayerportal.ird.gov.np → VAT → Return Filing → select Tax Period (Nepali month) and FY.
2. <strong>Enter sales:</strong> total taxable turnover + Output VAT (13% and any zero-rated export turnover separately).
3. <strong>Enter purchases:</strong> eligible Input VAT (only for taxable-supply purchases; apportion if mixed exempt/taxable).
4. <strong>Add adjustments:</strong> debit notes (+sales) / credit notes (−sales) for the period.
5. <strong>Review carry:</strong> opening credit from last period auto-applies if Input > Output previously.
6. <strong>System calculates:</strong> Payable = Output − Input − adjustments − opening credit. If positive, pay and get the voucher; if negative, the credit carries forward (exporters may claim refund per IRD procedure).
7. <strong>Submit and save:</strong> e-receipt/acknowledgement + payment voucher (if any) for your records.

<h2 id="calc">How VAT Payable Is Calculated</h2>

```text
VAT Payable = Output VAT (13% on taxable sales) − Eligible Input VAT (on purchases for taxable supplies) ± Debit/Credit notes − Opening Credit
```

- **Output > Input** — Pay the difference by the 25th
- **Input > Output** — No payment; excess = credit carried forward to next period
- **Exporter / zero-rated** — May claim refund of input credit per IRD refund procedure (separate from normal carry)

<h2 id="nil-credit">Nil Return, Credit &amp; Refund</h2>

- <strong>Nil return:</strong> select Nil/zero turnover for the period and submit by the 25th — required, not optional
- <strong>Credit:</strong> excess Input over Output is not cash back by default; it rolls forward as opening credit
- <strong>Refund:</strong> primarily for exporters making zero-rated supplies (VAT Act zero-rating) — file per IRD refund window with supporting invoices

<h2 id="penalties">Late Filing &amp; Interest</h2>

- **Late return (per period)** — Per-period fee per Finance Act (commonly in the ~Rs 10k–20k range; verify the current schedule — it changes) + recovery of any undeclared VAT
- **Unpaid VAT** — Annual interest on the amount due (rate per current Finance Act; interest runs until paid)
- **No activity ≠ no filing** — A registered person who had zero sales still owes a Nil return — the late fee still applies per missed period

<h2 id="invoice-rule17">VAT Invoice (Rule 17) Quick Check</h2>

- Seller: name + PAN + VAT registration number, invoice number + date (Nepali), buyer PAN/VAT where applicable
- Line items with taxable value per item, VAT 13% shown separately (not bundled), and total invoice value
- Standard vs abbreviated invoice format per VAT Rules 2053 Rule 17 — confirm your invoice template matches the latest IRD specimen
- A VAT invoice is what lets your customer withhold only 1.5% TDS (vs 15% on a PAN-only bill) — issuing a correct VAT invoice matters for your cash flow

<h2 id="mistakes">Common Mistakes to Avoid</h2>

- Missing the 25th — even for a Nil month
- Claiming input VAT on exempt-supply purchases or personal expenses (non-creditable)
- Not apportioning input when you sell both taxable and exempt goods/services
- Bunching debit/credit notes into the wrong period
- Forgetting to carry opening credit from a prior Input > Output period
- Issuing a VAT invoice without VAT shown separately (Rule 17 failure) — can trigger IRD observations

<h2 id="checklist">Monthly Checklist</h2>

- Sales + Output VAT (13% taxable + zero-rated export separately) reconciled to VAT invoices
- Eligible Input VAT from purchase invoices — exempt-use portion removed
- Debit/credit notes for the period entered
- Opening credit applied; payable vs carry computed
- File via taxpayerportal.ird.gov.np by the 25th; pay payable via connectIPS/eSewa and keep receipt
- If Nil — file Nil return (same deadline, zero payment)
