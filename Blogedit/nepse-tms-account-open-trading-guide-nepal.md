<h2 id="tldr">Quick Answer (TL;DR)</h2>

<strong>DEMAT → Meroshare → TMS (broker) → Bank/C-ASBA, all on one BOID.</strong> Open TMS online/in-branch with <strong>citizenship + photo + bank + DEMAT</strong>, get <strong>TMS login + broker code</strong>, load <strong>collateral via IPS</strong>, trade <strong>Sun–Thu 11–3</strong>. Cost ≈ <strong>0.36–0.40% broker + levies + Rs 25 DP</strong> per side.

<h2 id="chain">The 4-Link Chain — DEMAT, Meroshare, TMS, Bank</h2>

- **1. DEMAT/BOID (DP)** — 16-digit BOID holds shares — open via bank/broker DP with citizenship + photo
- **2. Meroshare** — meroshare.cdsc.com.np — IPO/FPO, portfolio, C-ASBA/CRN, DIS transfer
- **3. TMS (broker)** — Broker’s tmsXX.nepsetms.com.np login — live orders, collateral, ledger
- **4. Bank + C-ASBA** — Same-name bank + CRN for IPO blocking + IPS for TMS collateral load

Already have DEMAT? See <a href="/guides/open-demat-account-mero-share-nepal-2026">DEMAT + Meroshare guide</a> before opening TMS — reusing the same BOID avoids mismatch rejections.

<h2 id="broker">Choose Broker + Open TMS</h2>

1. Pick a <strong>SEBON-licensed broker (01–90+ codes)</strong> — compare collateral load speed, AMC, support, and nearby branch
2. Submit <strong>TMS + KYC form</strong>: citizenship, photo, DEMAT/BOID, Meroshare, bank + CRN, signature, nominee
3. Get <strong>TMS username/password + broker code</strong> in 1–3 working days → change password + enable 2FA
4. Load <strong>collateral via IPS/bank transfer</strong> to broker → limit appears in TMS → ready to order

<h2 id="trade">First Trade — Order Walkthrough</h2>

- <strong>Login TMS → Fund/Stock → Order:</strong> symbol, quantity, price (circuit limits per the current NEPSE notice — commonly ±10%, confirm the live circuit notice on nepse.org.np), validity (Day), buy/sell
- <strong>Market vs Limit:</strong> beginners use Limit at LTP ±1–2 ticks — market orders slip in thin books
- <strong>Settlement (commonly T+2 working days — confirm the current NEPSE settlement notice):</strong> bought shares in DEMAT in ~2 working days; sold cash in broker ledger → withdraw to bank
- <strong>IPO vs Secondary:</strong> IPO via Meroshare C-ASBA; live NEPSE buying only via TMS — do not confuse the two

<h2 id="charges">Charges & Mistakes</h2>

- **Broker commission** — ~0.36–0.40% per side, slab-wise per SEBON cap — confirm broker sheet
- **Extras** — SEBON + NEPSE levies (fractional %) + DP Rs 25/debit + bank IPS fee
- **Mistake #1** — Name/bank/BOID mismatch across DEMAT–Meroshare–TMS → collateral/transfer fails
- **Mistake #2** — Buying upper-circuit blindly at 3 PM — next-day gap-down; use limit + position size
