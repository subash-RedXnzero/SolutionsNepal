<h2 id="tldr">Quick Answer (TL;DR)</h2>

SEE Class 10 uses the same NEB <strong>4.0 scale: A+ 90–100 (4.0) → D 35–39 (1.6) → NG &lt;35 (0)</strong>. <strong>GPA = Σ(GP×CH) ÷ ΣCH</strong> (simple average works if credits equal). <strong>Pass = D in every subject</strong>; any NG needs the grade-increment exam. <strong>Percentage ≈ GPA×25</strong> — use only where accepted.

<h2 id="scale">SEE Grading Scale 2026 (Same as NEB 4.0)</h2>

- **A+ — Outstanding** — 90–100 → 4.0
- **A — Excellent** — 80–89 → 3.6
- **B+ — Very Good** — 70–79 → 3.2
- **B — Good** — 60–69 → 2.8
- **C+ — Satisfactory** — 50–59 → 2.4
- **C — Acceptable** — 40–49 → 2.0
- **D — Basic** — 35–39 → 1.6
- **NG — Not Graded** — Below 35 → 0.0

<h2 id="how-gpa">How SEE GPA Is Calculated</h2>

```text
GPA = Σ(Grade Point × Credit Hours) ÷ Σ(Credit Hours)
```

Most SEE subjects carry the same credit hours, so adding grade points and dividing by number of subjects gets you very close to the transcript GPA. The official marksheet weighting is definitive.

<h2 id="example">Worked Example (8 Subjects)</h2>

- **English (A) 82%** — 3.6
- **Maths (B+) 74%** — 3.2
- **Science (A+) 91%** — 4.0
- **Nepali (B) 66%** — 2.8
- **Social (C+) 54%** — 2.4
- **Opt Maths (A) 81%** — 3.6
- **Computer (B) 61%** — 2.8
- **Health/EPH (C) 47%** — 2.0

Sum = 24.4 ÷8 = <strong>GPA 3.05 → ~76%</strong> (B/B+ average). Use SolutionsNepal’s <a href="/nepal/education/see-gpa">SEE GPA Calculator</a> for your exact subjects.

<h2 id="passing">Passing Rule &amp; NG</h2>

- <strong>Two separate bars (per current NEB notices, as of October 2026):</strong> commonly cited as <strong>≥35 in theory AND ≥40 in practical/internal</strong> per subject — failing either bar yields NG for that subject even if the combined total looks passing. Confirm the current directive on <a href="https://neb.gov.np" target="_blank" rel="noopener noreferrer">neb.gov.np</a> for your exam year.
- <strong>Below the bar → NG (0.0)</strong> for that subject regardless of the other component's marks
- <strong>One NG →</strong> that subject not cleared; appear in the grade-increment exam to clear it

<h2 id="percentage">GPA to Percentage (GPA ×25)</h2>

```text
Percentage ≈ GPA × 25
```

- **4.0** — ~100%
- **3.6** — ~90%
- **3.2** — ~80%
- **2.8** — ~70%
- **2.0** — ~50%
- **1.6** — ~40%

<h2 id="vs-class11">SEE vs Class 11/12</h2>

- **Scale** — Identical (Letter Grading Directive 2078, 4th Amendment 2081/03/16)
- **Use of GPA** — SEE GPA for +2 admission; Class 12 GPA for bachelor / abroad / scholarships
- **Weighting** — SEE: check the current NEB subject schedule for credit/threshold splits (commonly described with separate theory/practical bars); +2: commonly described as 4 credits/subject with ~75/25 theory/practical split (CS often cited as 50/50) — both unconfirmed against the current curriculum as of October 2026, confirm on neb.gov.np

<h2 id="checklist">Calculator Checklist</h2>

- Enter each SEE subject grade point correctly (90+ =4.0, not 3.6)
- Use D=1.6 only for 35–39; below 35 is NG=0.0 (post-2079 rule)
- Divide by number of subjects (or weighted credits where given)
- For percentage use GPA×25 and label as approximate
